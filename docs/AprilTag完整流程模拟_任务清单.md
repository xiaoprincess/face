## 目标与使用流程

提供电脑端交互程序，模拟小智向树莓派 MCP 工具发起调用，执行云台转向、人脸识别和指定 AprilTag 定位。

程序启动 → 获取库存 → 弹出全部标签及库存信息窗口 → 用户浏览、搜索、选择标签或手动输入 ID → 执行 MCP 调用 → 云台转向人脸位置 → 拍照识别 → 返回定位位置 → 寻找目标标签并对准 → 显示结果。

本文件仅规定实现任务，不代表已经部署或完成硬件测试。

- [x] 实施前确认本地真实数据文件、数据库结构和更新时间。排除单元测试数据、演示样本及无法确定来源的旧备份，不凭文件名认定为当前库存。

- [x] 主列表字段：AprilTag ID、柜号、柜子名称/类别、零件名称、库存数量、单位、箱号、备注。

- [x] 同一柜子存在多个零件时，按柜子分组并列出全部零件；空柜子也展示，不能因没有零件而遗漏标签。

## 验收标准

1. 输入标签前必定出现库存窗口，正常情况下能浏览全部柜子及其全部零件。
2. 数据获取遵循“线上优先、本地仓库回退”，来源可见，失败不伪造或猜测库存。
3. 用户可选择或自由输入有效 AprilTag ID，且不会混淆柜号与数据库主键。
4. 单次执行能完成转向、人脸识别及标签定位，并返回真实的逐阶段结果。
5. 任一步失败、取消或超时均停止硬件；测试不产生借用记录或库存变更。
6. 所有部署变更有备份，可恢复到修改前版本。
