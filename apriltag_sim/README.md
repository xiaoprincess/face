# AprilTag 完整流程模拟（电脑端）

面向《AprilTag 完整流程模拟_任务清单》的 Windows 交互程序：先浏览库存、选择或手输
AprilTag ID，再通过 SSH 让小智 MCP 工具在树莓派上执行“转向人脸 → 人脸识别 →
对准标签”，并把每个阶段和最终结果展示出来。

程序只调用树莓派上已有的网站与 MCP 服务，不直接访问数据库，也不会创建借用记录或
扣减库存。

## 1. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（OpenSSH 的 ssh，或 PuTTY 的 plink） |
| Python | 3.10 及以上，只用标准库（tkinter 随官方安装包提供） |
| 网络 | 能访问树莓派网站（默认 http://192.168.0.103:5000）与 SSH（22 端口） |

启动方式：

1. 双击 run.bat；
2. 或在 face/apriltag_sim 目录执行 python main.py。

不需要 pip install。程序第一次启动会自动读取库存；读取失败会弹出原因和可选的本地副本。

## 2. 第一次配置

点击右上角「修改地址与令牌」，填写：

| 字段 | 说明 |
|---|---|
| 网站地址 | 树莓派网站地址，默认 http://192.168.0.103:5000；本机实测使用 https://192.168.0.100 |
| 设备令牌 | 与网站 PARTS_DEVICE_TOKEN、parts_mcp_server/.env 完全一致 |
| SSH 主机 / 端口 / 用户 | 默认 192.168.0.103 / 22 / xiao |
| 远程目录 | 树莓派上的 parts_mcp_server 绝对路径，默认 /home/xiao/face/parts_mcp_server |
| 远程 Python | 留空时使用 <远程目录>/.venv/bin/python |
| 主机指纹 | 可留空；首次测试会自动读取并弹窗确认，接受后保存到配置，后续通过 -hostkey 核验，无需提前在 PuTTY 中 accept |
| 私钥文件 | 推荐用密钥或 Pageant 登录；密码只在本次运行内存中使用，不落盘 |
| 定位时限 | 对准标签的最长秒数，10–180，默认 45 |
| 校验 HTTPS 证书 | 1=校验（默认），0=忽略；树莓派是自签名证书时填 0 |
| CA 证书文件 | 可把树莓派证书拷到本机后填写，替代关闭校验 |

配置保存在同目录 config.json（已加入 .gitignore）。环境变量 PARTS_DEVICE_TOKEN、
PARTS_WEB_BASE_URL、PARTS_REMOTE_HOST 等会覆盖文件中的值，适合临时使用。

### HTTPS 与自签名证书

树莓派 Nginx 默认使用自签名证书，对外是 https://192.168.0.100（443 端口，不是 5000）。
第一次连接如果报“HTTPS 证书校验失败”，可在设置里把“校验 HTTPS 证书”改为 0，
或把树莓派证书导出为 PEM 后填入“CA 证书文件”。

## 3. 界面与操作顺序

1. 库存窗口先出现：启动即读取库存，加载完成前列表和按钮不可用。
2. 浏览：左侧按柜子分组，展开后是柜内全部零件；支持按柜号、柜子名、零件名、
   箱号、备注搜索。主列表字段：AprilTag ID、柜号、柜子名称/类别、零件名称、库存数量、
   单位、箱号、备注。空柜子也会显示。
3. 详情：右侧显示数据库柜子 ID、柜子说明、零件编号、数据来源、来源地址、
   本次读取时间和库存数据时间；缺失字段显示“未提供”。
4. 选择标签：选中柜子后点「选择此标签」，或用「手动输入标签 ID」输入 0–586。
5. 执行测试：点击后先弹出确认框，显示目标标签、匹配柜子、数据来源、选择方式和
   “不会创建借用记录”的说明；确认后才连接 SSH 并驱动硬件。
6. 进度：独立窗口显示阶段列表、SSH/MCP 日志和结果；测试中可以「取消测试」。
7. 重试：完成后关闭进度窗口即可重新选择标签。

选择与浏览阶段不会驱动电机或摄像头；只有确认执行后才会。

## 4. 数据来源规则

1. 线上优先：GET /parts/api/device/cabinets（设备令牌认证，返回全部柜子和零件，
   不受关键词搜索条数限制），带超时与重试。
2. 本地回退：线上失败时扫描 face 工作副本中的库存数据库与导出文件：

   - unified_web_app/instance/*.db
   - face/*.db
   - 配置里指定的文件或 JSON 导出

   只以只读模式打开，不启动网站、不创建空库、不写回线上。
3. 来源必须可见：线上显示“树莓派实时库存”；本地显示“本地副本，可能过期”，
   并列出文件路径、文件更新时间、本次读取时间。
4. 多来源：存在多个可用文件时弹窗列出，由用户选择；不会静默使用旧库。
5. 全部失败：弹窗显示线上失败原因、候选文件及不可用原因，可重试、改地址、
   选择本地文件，或进入标注“未核实库存”的手动标签测试（该模式下仍可执行）。
6. 每次刷新/切换库存都会清空已选标签，避免“旧柜子 + 新数据”混用。

旧版站点数据库 equipment_system.db 因缺少库存数量等字段会被识别为不可用并说明原因。

## 5. 标签映射规则

- 现行约定：AprilTag ID = int(柜号)，不是数据库柜子 ID。
- 只接受十进制数字；非数字柜号、负数、超出 tag36h11 范围（0–586）标为
  “无有效标签映射”，仍然显示在列表里但不允许选择。
- 01 与 1 这类转换后相同的柜号会提示“重复映射”，程序不会自动选柜。
- 手动输入的 ID 即使不在库存中也可执行，但会明确标注“库存未收录，未核实”。
- 列表只是库存可推导出的标签，不代表摄像头已经看见这些标签。

## 6. 执行、超时与取消

执行链路：

   本机 plink/ssh → 树莓派 parts_mcp.py（stdio MCP）
     → initialize → notifications/initialized → tools/list
     → tools/call test_face_and_point(tag_id, timeout_seconds)
     → 网站 /parts/api/device/tag-test（后台任务 + 轮询）
     → 转人脸位、拍照、人脸识别、云台对准、释放资源

- 人脸阶段与树莓派旧流程（web/start.py）逐项一致：每次都是 640×480 RGB888 配置 →
  启动 → 0.5 秒预热 → 抓拍 JPEG → 停止 → 百度搜索（不带质量/活体参数，阈值 70），
  失败后 2 秒重试，最多 30 秒；进度窗口显示“人脸识别（第 N 次）”。
- 标签搜索连续看不到目标默认 8 秒才判 lost（旧代码 30 帧≈2.3 秒偏短），
  可用 PARTS_TAG_LOST_TIMEOUT（2–30 秒）调整。
- 每条阶段状态来自树莓派返回的 progress 通知，并最终显示逐阶段耗时。
- 取消：客户端发送 notifications/cancelled，并直接用设备令牌请求网站取消接口，
  等网站任务进入终态后才返回；服务端收到取消标记后停止对准/人脸重试、关闭指示灯、
  释放相机，电机由紧急停止兜底。界面会提示“等待硬件停止”。
- 超时：定位时限由 timeout_seconds 控制；服务端还有最终时限兜底。
- 结果只有 aligned 才表示“通过人脸且目标已对准”；lost、timeout、cancelled、
  face_failed、hardware_unavailable、error 都会如实显示。

测试流程不写借用记录、不改库存；网站侧已用测试断言覆盖这一点。

## 7. 安全说明

- 设备令牌只放在本地 config.json 或环境变量，不写入日志。
- SSH 密码只保存在内存，不写配置文件；推荐密钥或 Pageant。
- 日志不显示令牌、密码、百度密钥和原始人脸图像。
- 默认要求 Plink 主机指纹；未配置时 Plink 会拒绝连接，而不是静默信任。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 设备令牌被拒绝（401/403） | 令牌与网站不一致 | 核对三处 PARTS_DEVICE_TOKEN |
| 无法连接网站 | 地址/端口/网络不对，或网站未启动 | 改地址、检查树莓派服务 |
| 找不到 Plink | PuTTY 未安装或路径不对 | 安装 PuTTY 或改「Plink 路径」，也可用 ssh 模式 |
| Host key 被拒绝 | 已保存指纹与主机不符 | 确认地址及树莓派是否重装；确认后在设置中清空主机指纹，下次测试会重新弹窗确认 |
| MCP 未提供 test_face_and_point | 树莓派 parts_mcp.py 未更新 | 按《交付说明》部署后重启 MCP |
| 人脸未通过 | 未注册、光线或角度问题 | 先在网站完成人脸注册，再重试 |
| 定位 lost | 目标不在当前视野 | 第一版只在视野内定位，需要人工把柜子移入画面 |
| 定位 timeout | 时限太短或标签太小/太远 | 调整时限，检查标签与相机 |

## 9. 测试

在 face/apriltag_sim 目录运行：

    python -m unittest discover -s tests -t . -v

18 项测试覆盖：标签映射（数字、前导零、非数字、越界、重复、排序、统计）、
线上库存解析与令牌失败、本地只读回退与旧库识别、MCP 握手/工具检查/进度/取消。
这些测试不访问网络、SSH 或硬件。
